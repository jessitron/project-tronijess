# Tronijess

A multi-agent system organized into bounded contexts (domain repositories).

## Structure

This project is organized into three domain repositories, each representing a distinct bounded context:

- **domain-tasks**: Task management and coordination
- **domain-code**: Code creation and modification
- **domain-learning**: Knowledge capture and architectural decisions

Each domain has its own README and agent prompt defining the responsibilities and capabilities of agents operating within that context.

## Getting Started

Navigate to individual domain directories to understand their specific roles and responsibilities.
